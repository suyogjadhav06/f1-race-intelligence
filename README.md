# f1-race-intelligence

F1 Race Intelligence Dashboard
An interactive Tableau project that explores Formula 1 performance and race trends. It includes driver and constructor performance, podiums, driver nationality, DNF patterns, and reliability by season. The dashboard contains bar charts and other views to help compare drivers, teams, and race outcomes.

A Tableau Story presents selected visuals in a guided sequence, including a reliability and global results section.
